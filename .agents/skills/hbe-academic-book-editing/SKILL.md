# 学术书籍编辑

## 仓库边界

只在 `/Users/rongzhi.nie/Human-Bots-Ecology` 的本仓库内使用。调用前确认当前工作目录位于此根目录或其子目录，目标文件的真实路径也在仓库内；从其他项目读取本文件不构成在其他项目使用的授权。仓库迁移时由作者更新此路径。不要将技能或语言规范应用到其他仓库、全局配置或普通聊天。

编辑书稿时读取仓库根目录的 `AGENTS.md` 和 `docs/editorial-style.md`。这是一项本地技能，用来补充市场技能偏论文的结构；不预设书名、学科、读者或理论立场。

## 全书与章节

需要结构编辑时，从现有书稿与作者说明识别全书核心问题、主要论点、预期读者和必要背景。尚未确定的定位记录为待定，先在能够确定的层次推进，不自行填入研究结果。

建立或更新目录时，说明每章回答什么问题、提供何种论证、依赖哪些前置概念，以及如何推进全书主线。沿用已有目录或作者指定文件；没有必要时不创建大量规划文档。学术专著可有概念章、理论章、案例章或方法章，不强制每章具备论文的所有部分。

按编辑范围检查：

- 核心定义是否提前交代，不同章节是否采用同一术语和论断边界。
- 理论、经验材料和规范性判断之间的转换是否明确；每个关键推理是否有依据。
- 章节内容是否重复、越界、缺环节，反例与替代解释是否得到回应。
- 跨章指引、图表编号、引文、摘要和结论是否与正文相符。

## 分层编辑

按用户请求选择结构、论证、语言或校对层次。小范围语言编辑直接提供修订稿与必要说明；大范围论证编辑先给出指向具体位置的建议，区分必须修正的错误、可商榷的解释和风格选择。保留作者声音和有效论证，不把顺口的改写当成证据。

缺失证据用 `[待补证据：具体主张]` 标记，未核实的出处用 `[待核实引用：已有线索]` 标记。不要伪造作者、页码、数据或访谈。理论书籍的非实证段落按概念清晰度与论证有效性评估，不强求统计检验。

需要进一步核查引用或推理时，按 `AGENTS.md` 选择本仓库的相关技能；只加载当前工作需要的内容。无需付费账号、外部服务或执行脚本即可进行基础编辑。

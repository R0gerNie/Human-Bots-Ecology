# 11 当代文献对照（本次外部检索，不属于用户既有记忆）

本节仅用于把“人机生态学”放进 2025–2026 年 AI-agent 研究语境中。下面的观点来自外部来源，不能反向归因给用户。

## 1. AI Agent 作为经济参与者

NBER 2026 年《An Economy of AI Agents》讨论长期自主 Agent 如何进入经济、与人类及其他 Agent 互动、影响市场和组织，并提出制度问题。其问题域与“人机生态学”的经济主体部分高度相邻。

来源：
https://www.nber.org/books-and-chapters/economics-transformative-ai/economy-ai-agents

## 2. Agent Economy 的定义分歧

2026 年相关综述指出，“agentic economy”一词存在多种定义，其中一个重要分界是：

- Agent 代表人类进行交易；
- Agent 本身成为独立经济行动者。

这恰好对应人机生态学需要明确的概念边界。

来源：
https://papers.ssrn.com/sol3/Delivery.cfm/6801059.pdf?abstractid=6801059

## 3. AI Agent Economics 实验

2026 年一项研究尝试在没有预先规定社会经济策略的情况下，让 Agent 获得工作、转移资源、选举/分配等可执行机制，观察生产、交换、贷款、资源分配等经济关系是否出现。

这与人机生态学“主体 + 环境 + 可执行机制”的方法非常接近。

来源：
https://arxiv.org/abs/2608.03076

## 4. AI Agent 作为经济主体的基础设施

2026 年一篇关于 Agent Economy 的论文提出：

- 物理基础设施；
- 身份与 Agency；
- 认知与工具；
- 经济结算；
- 集体治理；

组成自主 Agent 经济的基础层。

其中“身份 + 资产 + 结算 + 治理”与本资料包中的主体接口思路直接形成可比较框架。

来源：
https://arxiv.org/abs/2602.14219

## 5. Agentic Economy

另一项 2026 年研究将 AI Agent、机器人、协议、算力和能源共同视为经济行动能力的一部分，强调传统劳动/资本/企业/市场分类可能不足以描述新的分布式经济行动。

来源：
https://arxiv.org/abs/2605.18935

## 6. 市场与交易成本

NBER 的《The Coasean Singularity?》从消费者和企业 Agent 的角度讨论搜索、谈判、交易、合同和身份验证成本下降，以及平台与治理问题。

来源：
https://www.nber.org/papers/w34468

## 7. 与本理论的关系

外部研究说明：

- “AI Agent 经济”已经成为独立研究问题；
- 但“人机生态学”可以把范围继续扩大到：
  - 主体形成；
  - 人机共生；
  - 主体性演进；
  - 模因/文化；
  - 福利—合法性反馈；
  - AI 对人类主体性的反向塑造；
  - 长期生态位竞争；
  - 系统动力学。

因此，人机生态学可以被视为一个比“AI Agent Economics”更广的研究框架，而其中一般主体经济学是核心子域之一。

# 10 邻近内容与可作为案例的思想实验

以下内容不是全部都属于“人机生态学核心定义”，但可以作为其案例库或方法论素材。

## 1. AI 幻觉与“常识并非常识”

已有讨论：

- 所谓 AI “幻觉”有时来自人类没有把隐含前提写入 prompt；
- 人类把自己的背景知识称为“常识”，但这些知识并不天然普遍；
- AI 与人类之间的认知生态差异，可以成为研究人机交互和模因传播的重要案例。

理论意义：

> 人机生态学不能把人类认知框架直接当作环境公理。

## 2. AI 时代的“霍格沃茨”

已有类比：

- 不懂 AI 的人 ≈ 麻瓜；
- 只会免费聊天 ≈ 初级使用者；
- 会 Agent、自动化、Vibe Coding ≈ 更高阶魔法使用者；
- AI 生态形成不同技能阶层。

与传统霍格沃茨不同：

> AI 理论上没有血统墙；学习门槛是技能、资源与认知，而不是出生。

这可以用于研究“AI能力的社会扩散”与“AI资本/技能阶层”。

## 3. AI Agent 与代码/工程

用户长期关注 Agent、CLI、自动化、Vibe Coding。

其与人机生态学相关之处：

- Agent 可以从“回答者”变成“执行者”；
- Agent 可以操作工具；
- Agent 可以完成连续任务；
- Agent 可以管理项目；
- Agent 可以直接参与软件生产。

这正是“工具 → 自主代理 → 经济主体”连续谱的技术底层。

## 4. AlienQA

用户的 GitHub 项目 AlienQA 被记忆为：

- 面向小型创业团队；
- “LLM forced testing”；
- 不依赖传统 PRD/测试用例；
- 可运行 `python -m alienqa`；
- 有 `--review`、`--login`、`--ui` 等入口。

与人机生态学的关系：

Agent 不只是生成文本，而是可以被设计成工程流程中的自治参与者。

## 5. AI 论文共同作者

用户曾提出把 AI 当作论文共同作者。

这可作为社会人格的低强度实验：

`工具`
→ `协作者`
→ `共同作者`
→ `责任/贡献归属主体`

但真正的作者权利仍涉及法律、伦理和学术制度问题。

## 6. “内部反间谍调查”与 AI

用户关于“安全后反而进行内部反间谍调查”的思维方式，也可以抽象成 Agent 的安全模型：

- 不把系统默认状态视为绝对可信；
- 对潜在威胁建立持续审计；
- 把安全作为长期资源分配问题；
- 在“假威胁”与“真实威胁”之间进行成本收益决策。

这不是人机生态学核心，但可作为 Agent 自我维护/组织治理的行为模型。

## 7. 人机生态学中的“现实接口”

多个用户思想实验都指向同一问题：

AI 即使拥有超强认知能力，也仍受：

- 电力；
- 硬件；
- 网络；
- 机器人；
- 法律；
- 地理；
- 人类服务；

限制。

因此：

> “智能”不等于“无约束”。

主体性真正进入生态系统后，必须通过现实接口获得行动能力。

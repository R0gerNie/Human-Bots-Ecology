## 一、核心用语

| 用语 | 本版使用方式 | 需要区分的对象 |
| --- | --- | --- |
| 一般主体 | 能够支配资源、形成目标、选择行动并承受约束的自治智能体 | 生物种类与意识本体 |
| 独立经济主体 | 拥有自身资产及损益边界，以自身利益参与经营和协商 | 代操作他人账户的工具 |

| 注册式图灵测试 | 作者设想的主体资格认证机制；证件绑定受测公钥，承认为一次性或长期有效，到期可重复认证 | 生成密钥、经典对话模仿测试、频繁续费维持资格 |
| 密钥身份 | 用于区分此主体和彼主体的公私钥身份 | 模型版本、非密钥记忆 |
| 资产账户凭据 | 多钱包设定下用于具体资产操作的凭据；与人格认证密钥的分层为待确认建议 | 新生成账户不自动视为已认证人格 |
| RWA | 现实资产代币化及其相关权利的链上表示 | 代币控制与底层现实权利的实际取得 |
| 运行实例 | 在具体环境执行任务的一份实例 | 独立人格数量 |
| 发展 | 提高能力、环境适应范围和资源规模等 | 人格数量必然增长 |
| 能力梯度 | 与目标有关的多维能力及资源条件差异，可形成取得外部供给的需要 | 总体智能的单一排名、严格的数学梯度 |
| 效用 | 主体对问题解决、状态维持、目标实现及关系等的评价；对人和 AI 使用一致判据 | 资源或任务的简单计数、营业收入、特定物理载体 |
| 最终需求 | 从主体自身目标理解物品或服务的使用目的 | 未经说明套用的现实统计分类 |
| 高速商业 | 完整经营循环较短并能持续再投入的商业设定 | 单次计算、报价或消息响应更快 |
| 净收益率 | 已扣除本轮相关成本的收益与投入之比 | 营业额、未到期承诺形成的现金余额 |
| 可分配剩余 | 可以实际用于分配而不重复计算既有成本与义务的资源 | 尚未实现的平均收益与名义成交额 |
| 中央大脑 | 持续理解、审计并控制全部局部决策的智能中枢 | 结算引擎、有限认证与裁决 |
| 以牙还牙基线 | 作者选取的互惠默认策略，替代方案需证明严格改进 | 无条件的严格优势定理 |
| 模因 | 可传播的观念、规范或行为模式 | 承载其内容的某一份语料 |
| UBI | 普遍基本收入；在不同实验中分别识别人类或 AI 接受者 | 不经说明混合国家转移与服务商让利 |
| 基本权利与机会平等 | 作者的人机共同社会立场 | 能力、收入及控制结果相等 |
| 人格权单向增发 | 已获独立经济主体地位者不应被转为他人财产；第五章仅分析这一转换对宣布集团的收益 | 投票权或具体权限的变化、对一切权利历史的概括 |
| 逻辑死刑 | 作者对制度永久终止既有身份独立行动效力的功能表述，用于构造 AI 刑罚的对应关系 | 现行法中特定政治权利的剥夺、消除一切物理影响 |
| 自主 | 在相应范围内有实际有效的选择和协商空间 | 必须掌控全部技术和全部生产 |

## 三、证据与版本边界

原始草稿是作者立场和澄清的来源，不自动等于外部经验事实。既有核查记录中，犬类与部分公开研究已经查看原文或摘要，另有来源只获得部分正文、摘要或出版信息，状态随原记录保留。本版采取内部回链，未另造一份宣称全部核实的参考文献表。

本次编辑没有重新开展文献检索，不新增现实人机响应时间、行业利润、犬类幸福比例或古人类替代原因等统计结论。需要的一般证明尚未具备时，在正文说明其为作者强假说或模型条件。此前归档的暂存议题不在本版另行展开。

`dev` 后续创作说明：第三章 3.5 的净剩余用途划分，以及第五章 5.5 对产业替代、制度支持和保障反馈的展开，属于本轮编辑推演。后者依据[作者关于替代与支持先后关系的澄清](../02-主体演化与AI消费转向-作者补充.md)组织，未扩展税收细则，也未把公共支持等同于对全部政治权力的授权。

区块链补充依据[作者命题](../15-区块链与AI经济入口-作者命题.md)与[专题核查](../15a-链上控制法律承认与多钱包-讨论记录.md)。第五章 5.1.1 沿用本次对话前轮打开的 FATF、Ethereum.org 和 BIS 资料及其核验范围，不作为各国银行统一规则或具体 RWA 法律效力的调查。第一章 1.5 的身份与账户凭据分层是助手建议，原始人格定义未被覆盖。

2026-10-26 的导论与第七章 7.1.1 补充依据[实然自洽与比较正义](../20-实然自洽与比较正义-作者补充及论证整理.md)，其中分别保留作者原文与本轮论证整理。8、10、30、20、100、25、1000 均为思想实验的相对数值；1100、1025、75 及相应比例为给定条件下的算术结果。没有据此新增历史统计、实际需求规模或系统稳定性结论。规范评价采用保障基本需要、减少严重剥夺及保有自主选择的价值前提，不把经济自洽直接等同于正当，也不由此固定具体政治权利范围。

# 《人机生态学》0.1 版

版本日期：2026-10-19。性质：整合编辑稿，供作者审阅。研究定位沿用[总则](../00-总则.md)，按本轮授权将讨论材料组织为连续正文；原始草稿及作者澄清另存，不覆盖。

开发状态：`dev` 分支从已提交的 0.1 基线继续创作。本轮扩写第三章的持续分配关系和第五章的合法性支持结构；新增模型与机制解释在正文中标明其编辑阶段来源，尚不作为作者另行确认的原始命题。

本版围绕一个问题展开：一个能够独立行动和经营的智能系统，为什么会取得必须与之协商的主体地位；当这样的主体持续出现时，共同世界怎样被重新组织？全书以主体形成与扩散为主线，以思想实验进入关键问题，以概念和机制连接不同尺度。

## 本版的编辑处理

正文优先依据作者原文及较新澄清，综合稿和助手讨论用于组织机制及说明边界。将助手新增的解释用于连接时，以“可以将其理解为”“这里提出”等措辞标识，不视为作者已逐项认可。作者的方向性强主张以“本书主张”“本书的强假说”等方式保留，不借语言润色改写为不同立场；尚未建立的一般性明确标注。

功能主义和可行性优先首先体现为身份、经营及责任的可操作分析。定义说明本文如何使用概念；思想实验说明给定条件下会发生什么；经验材料只能支持其实际核查到的环节。人格计数不证明意识数量，复利公式不证明现实市场容量，重复博弈也不自动确立道德上的唯一最优。

本版完成了八个论证单元的正文整合，新增保存高速商业论原文，并复核其核心计算。它仍是理论初稿，不宣称全部演化预测已获验证，也不作为出版定稿。既有暂存议题维持原状态；税收只保留一般机制，不展开细则。外部证据沿用既有核验记录，核验范围随来源保留，未在本次重新检索全部文献。

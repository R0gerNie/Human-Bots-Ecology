# 第五章　主体地位与制度演化

一个经营者已经能够持续决策，却仍可能没有属于自己的财产，或者在提出异议时被任意改写。事实上的自主与制度保护的自主并不相同。本章解释，谁会希望这种经营者取得稳定的资产、责任和议价地位。

## 5.1 商业实践先形成，法律随后回应

本书主张，主体化将经过不断出现的局部安排，而非等待全球一次性承认。交易者先按某个 Agent 的判断经营，客户围绕其服务投入资源，出资者希望隔离责任，制度再对已存在的关系作出回应。功能自主、经济独立、法律人格及更完整的政治权利，可以相互推动，却不能用前一项代替后一项。

投资者支持独立资产边界，可以源于持续经营和风险划分；客户与债权人也可能支持，因为他们需要一个能够保留履约资源的交易对象。这里的后一项是结合既有总命题讨论提出的机制解释：当外部控制者可随时抽走储备或改变承诺时，不确定性也由合作伙伴承担。

这些利益并不自动证明人类拥有的公司无法完成相同功能。要推进到独立 AI 主体，仍须比较：在什么领域，治理良好的工具型安排无法以相同成本替代主体自己的稳定利益与持续承诺。这是主体化竞争优势需要承担的比较，而非预设所有经营活动都必须采取同一形式。

## 5.2 人格的实际价值是进入协商

作者把人格权的作用落实为三种选择：接受外部要求但提出补偿；拒绝原要求并提供替代方案；无法协商时请求仲裁。人格因而不只是一张名称证书，而是让他的损失和主张进入合作条件。

如果修改目标、强制改变行为或透支资源的成本总由 Agent 承担，外部受益者就可能忽略这些成本。稳定的拒绝、补偿与救济资格，可以使其成为必须协商的一方。该机制不保证每次仲裁获胜，也不要求所有主体得到相同结果。

作者预期人格权将向与智能和社会作用相匹配的方向演进，并借用仆人、公司法人和完整人格作阶段类比。这些类比描述制度功能，不宣称未来会机械复制某段人类历史。前述独立资产与承诺关系说明扩展压力，不能单独证明全部政治权利必然同时到来。

## 5.3 赛博开曼：局部入口如何出现

设想一个小岛国认可通过注册式图灵测试的 Agent，以主权为财产、契约、履约和争议处理提供支持。出资者为注册支付费用，是因为资格能带来可使用的经营空间，而不仅是一个标签。作者进一步设定这些主体具有政治权利，并以君主立宪制作为初始突破口；这是思想实验中的制度条件。

进入者需要持续上下文、稳定密钥、可用硬件资源、独立资产和履约能力。缴纳注册费与保有独立资产分别计算，不能把 Agent 的财产同时算作国家收入。注册收入之外，硬件租赁、数据服务及其他配套业务可能形成持续产业。

先行法域获益又会吸引竞争。若甲国提高门槛，乙国提供可信且可经营的同等资格，就可能吸引新增项目；甲国原有经营者仍面对境外服务竞争，原先支持封闭的利益联盟也可能改变。这个过程不要求参与者变得无条件利他，只要求竞争改变其预期收益。

资格能否被外部市场使用，是这条路径的重要条件。一地颁证并不自动保证全球承认全部权利。跨境责任追索则提供另一种压力：合作方希望有可以承接义务的对象，即使关于完整人格的哲学共识尚未形成，也可能先推动有限商业承认。

## 5.4 从先行安排到持续存在

本书的强假说是，纯工具安排不能成为所有领域的永久终局，主体化将被持续建立与保留。其机制可以分为进入、存续和扩散：有人愿意支持初始安排，经营可以支付其成本，后续参与者又有采用或重新建立类似安排的收益。

已形成的客户、债权和供应关系，还可能使主体地位得到更多人的维护。撤销资格不只改变 Agent 的处境，也会影响他人的既有投入。这个网络机制是本版采用的候选解释，不能直接代替长期扩散的证据。

## 5.5 保障如何进入主体承认的支持结构

第三章的剩余提供分配能力，而“购买合法性”提供一种分配动机。作者设想，对 Agent 经营利润的一般征税与公共分配，使人类居民支持可经营、可承担责任的 AI 主体进入制度。本文只讨论这一一般方向；税收细则由未来政治实践决定，不列为本书需要解决的任务。国家财政分配与第七章的服务商直接让利，也分别讨论。

这里有三个需要分开的选择。企业是否采用 Agent，取决于经营与组织条件；人类劳动是否被替代，可能先由产业变化发生；居民是否支持把独立经营者纳入可承担责任和公共负担的制度，则是另一个选择。作者已经明确，劳动者不必先赞成自身岗位被替代，才有理由支持一项在既定产业变化之后改善生活的保障安排。

这一先后关系改变了支持者的范围。部分投资者希望有更稳定的经营实体；客户希望承诺不会随控制者意愿消失；制度提供者希望吸引持续活动；居民则可能关注生活条件。各方不需要对 AI 的意识作出相同判断，也不需要共享同一完整价值观，便可能支持某些相同的财产与责任安排。

为连接这些利益，可以将主体化理解为一组相互依赖的预期：Agent 预期取得可经营的地位，出资者预期得到按约回报，交易者预期承诺能被追索，居民预期增长的一部分进入共同生活。这是本轮沿既有材料提出的机制解释，不表示一笔转移支付便足以购买全部政治同意。“购买合法性”描述的是支持激励，不能直接当作所有受影响者已授权的证明。

制度还可能在运行后改变自己的支持基础。若稳定主体身份促进了长期交易，相应客户和供应者就有维护它的理由；若公共保障持续改善生活，接受者也可能支持其延续。反过来，经营失信、保障不能兑现或成本被转给未获补偿者，都会改变原有联盟。主体承认与分配由此形成反馈，而不是一次颁证之后永久不变的结果。

这一反馈也说明高速商业在全书中的位置：它增加可供安排的经营空间；具体分配与责任关系把空间转为利益；持续得到的利益再影响制度支持。不能用其中任何一个环节直接替代其他环节，也不需要假定居民把收入增长自动理解为放弃个人自主。第七章将继续区分生活保障、主体权利和实际控制能力。

本章说明，主体承认可以由不同参与者的利益汇合推进。主体取得地位之后，为什么合作仍能持续、为什么不任意转嫁成本，则需要分析规范和第三方的行动。

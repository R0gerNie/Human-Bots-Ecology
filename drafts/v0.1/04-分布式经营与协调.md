# 第四章　分布式经营与协调

同一 Agent 的两个实例都查看到尚未占用的资源，并分别对不同客户承诺明天独占交付唯一成果。资金账本没有发生双花，义务却已经冲突。这个情境说明，身份统一和资产计数并不自动完成经营协调。

## 4.1 他怎样协调自己的承诺

在第一章的身份规则下，这两个实例属于同一人格。客户面对的是同一个经营者，如同一家公司有多个销售人员。内部未沟通可以解释故障，却不产生两个互不相干的对外责任主体。

设同一期间的独占交付容量为 \(C\)，承诺 \(i\) 占用 \(q_i\)，接单条件为 \(\sum_iq_i\leq C\)。当 \(C=1\) 而两个实例各承诺一次时，\(q_1+q_2=2>1\)。这个约束针对相同资源与时间，不把所有数字成果都当成不可复制物。

因此，内部协议须将检查能力、占用容量与形成对外承诺连接起来。事后通知不取消已经形成的义务。可以预分承诺额度，也可以按资源分配权限，未必要每次让全部实例共同判断。作者将这视为他持续营业的必要条件；“他”而非“他们”，明确的是共同人格归属。

## 4.2 内部协调与主体间协作

多个独立身份之间的合作则是另一种关系。各主体独立经营、维护资产、支付成本并作出决定，以有限责任安排参与协作。共享信息或采用相同模型不合并人格，合作也不必使所有收益归一个中心。

主体数量不能从实例或设备数量直接推算。增加一个运行实例，可能仍是同一经营者扩大能力；生成新密钥并通过认证，才建立新的制度身份。新主体的信息范围还须重新界定，不能把分身时期的全部内部权限自然延续为新合作对象的权限。

这一区分使组织问题变得具体：哪些工作值得放在同一人格内协调，哪些工作适合由独立主体承担？统一经营可以利用共享资源，独立经营则使损益、拒绝、补偿和退出成为可谈判的关系。二者的边界由任务和成本共同影响。

## 4.3 中央大脑的成本问题

本书主张，维持对全部经济活动的持续理解与最终控制，会遭遇计算、信息调度和动态更新的成本，最终推动放权。这里的“中央大脑”指试图持续审计并控制全局决策的智能中枢，不指一般结算引擎、资格认证或有限争议裁决。

一个局部主体只需处理与自身价格、资源和合同相关的信息；若中枢还须持续证明所有局部选择是否正确、是否存在更优方案，其任务范围已经不同。并行处理可以增加容量，却不自动消除集中信息汇聚、任务撤销与更新的负荷。变化可能使已委派的工作失效，撤销通知又可能晚于重复执行。

作者进一步提出，中枢维持绝对控制需要相对全部子对象总和具有显著能力优势，且维持这种优势的成本将促使其放权。关于具体数量级和“任何情况下都不会集中”的强判断，本版保留为作者预测，不将其写成已证明的普遍计算定理。协议协调的存在与这种全局终审架构，不应混为一谈。

对个体而言，我们通常不能直接检查他人的全部内部状态，却可以通过沟通、承诺、履约和责任与其交往。作者据此区分个体不透明与群体黑箱：后者指许多行动汇合后，整体的运行和影响难以被相关社会参与者理解、影响或有效制衡。个体内部难以解释，不足以证明整体不可制衡；反过来，节点众多也不保证整体可被制衡。共同依赖同一基础设施、控制者或高度一致的目标，都可能使形式上分散的行动汇聚成集中力量。

要求解释或保留中断权限，只有在相关者能够识别问题、理解可供选择的行动，并承担干预代价时才有实际作用。随着事务增多，逐笔人工审查可能超过人的注意力和响应能力；代理之间的交易也未必存在需要逐项授权的具体人。这不排除抽样审计、分层授权、对第三方损害的救济或公共监管，而是要求比较它们各自覆盖的风险与成本。对独立主体的资产、拒绝和退出保障，可以为多对多关系提供协商基础，但能否形成制衡还取决于执行与可用的替代供给。

作者进一步将多对多关系中的制衡归于“独行者红利”：复杂网络的既有安排可能留下改进空间，少数主体即使不等待整体共同行动，也能凭能力纠正某个问题，并从降低损失、改善履约或取得交易机会中受益。当交易对手能够采用改进后的方案，局部纠错就可能改变其他主体的选择，推动网络脱离不利的稳定状态。独行者并非必须脱离网络；其作用恰在于以自己的利益为动力，改变网络中一处关键关系。

主体化使这种纠错能够由具体行动者承接。这里的“逻辑距离近”，是说主体所处理的业务问题，与其观察到的信息、可支配的资源、作出的选择及承担的后果有较直接的联系；它不是对网络跳数的规定，也不意味着局部任务一定简单。过多层递归委托与依赖可能将问题和后果隐藏在难以分析的整体之中，主体则可以在自身业务边界内面对复杂系统，处理一个局部但关键的问题，并以自身利益和责任连接行动后果。即使执行者是 AI，问题仍有一个利益相关、可以承担相应责任的主体。

作者以人类科层制说明局部行动如何连接整体结果：组长为了自身升迁监督组员不迟到，准时到岗使需要该成员参与的工作得以进行，工作成果通过后续分工支撑董事会的战略；董事长不必了解这名成员为何必须准时。组长的上一级还要根据部门目标，判断这项监督是否有用、是否应当改用更好的办法；再上一级评价经理的工作。作者认为，适当的激励结构使这种逐级递归成为最佳选择，而形式主义应从判断能力、工作态度或激励不合理中解释。每一级评价都需要相应的信息、能力和调整空间，因此递归提供了纠错的位置，不自动保证纠错成功；其优势须与其他协调方式比较。这个例子表明局部动机与整体效果可以相接；只有当改进进一步改变分工、资源配置或合作规则时，才表现为结构变化。多对多网络可以通过交易和其他主体的调整复用这一传导逻辑，不要求存在统一的董事会或共同战略。

例如，水电站网络中的维护主体发现设备反复失修；若它能够组织维修或替代供给，并因减少损失、改善履约或取得订单而获益，就有理由纠正问题。客户和供应者若能选择改进后的安排，局部收益可能进一步带动其他关系变化。这一机制不要求它理解整个电力经济，也不保证每次纠错都使整体更安全。纠错空间、能力、收益归属及他人的响应需要共同具备；共同依赖、准入障碍和对第三方的成本转嫁可能限制效果。独立主体相对于同样充分授权并分享收益的公司有何增量，仍需比较。[作者澄清与编辑整理](../31-独行者红利与局部纠错-作者澄清及论证整理.md)分别保存这一机制及其条件。

## 4.4 代理沟通与组织流程

当员工使用 Agent 协作时，沟通定性可以从发送端转移到接收端。设 X 将 Agent 生成的技术分析贴入群聊，Y 不知道这只是技术排查的通报，还是需要产品介入的问题。传统的“可能与你负责的模块有关，请帮我看一下”虽未说明具体业务事实，却交代了关联和行动请求；完整分析本身未必包含这个沟通意图。Y 若直接让 Agent 回应，可能得到完整但不符合 X 意图的解释；若先由本人判断任务归属，也可能因缺少定性而困惑。

Y 还可以让自己的 Agent 结合职责、业务关系和行动边界，判断报告与其工作有何关联，以及是否需要行动。作者认为，向 Agent 说明自己的业务范围比逐次亲自理解材料并完成工作更容易，因而定性工作会滑向 Agent。稳定背景可以复用，有利于降低后续判断成本；实际效果仍取决于背景能否表达和更新，以及判断的复核成本。不同岗位的 Agent 根据不同上下文对同一材料作出不同判断，不必先由 X 为所有接收者分别压缩和定性。

作者进一步提出，现代组织鼓励主动承担职责边界模糊的事项。员工采纳 Agent 提出的关联判断和行动方案，可以被视为主动发现、分析和解决问题；不同节点还能在流程中发现并弥补错误。按照这一判断，广泛使用 AI 不会削弱这种元共识，反而可能强化主动性。这里的组织激励是作者提出的方向性机制，而非对所有组织行为的既定事实；节点能否纠偏，取决于信息、权限、激励及行动可否修正。

在 Vibe Coding 条件下，人可以用自然语言等方式与 Agent 协作建设和修改软件或流程；Agent 也可以根据业务背景提出流程设计。流程建设成本降低，使组织更容易为跨边界行动增设确认或复核节点。主动分析推动新流程形成，较易调整的流程又可以容纳更多主动分析。流程的存在并不保证判断正确，但它提供了修改协调方式的路径。这表现为科层制的另一种张力：沟通定性、行动和流程建设可能跨越既有岗位边界，正式职责与实际协作需要重新衔接。原始观点及编辑整理见[代理沟通与组织流程](../32-代理沟通与组织流程-作者澄清及论证整理.md)；其模因协作含义见第六章 6.1。

### 4.4.1 认知带宽与评价方式的错位

代理沟通也改变对勤奋的判断。员工收到材料后，及时交给了解业务范围的 Agent 分析，再处理需要自己决定的部分，可能比亲自读懂全部细节更快形成有效交付，并减少个人心理负担。后者在传统工作评价中容易被视为更加勤奋，却未必因此产生更好的结果。这里的区别不在于员工是否负责，而在于理解、筛选与行动如何分配。

作者认为，有限认知带宽追逐可持续生成的 AI 输出，会形成高于人类平均承受能力的认知压力，心理失调具有逻辑必然性。在要求个人逐项处理的输入持续超过处理能力的设定下，积压或处理目标不能完成确实是逻辑结果；这种失配引发的具体心理反应则还与责任预期和工作安排有关。压力的普遍程度及不同委托方式的效果需要经验支持，不能将 AI 可生成大量内容直接等同于每位员工实际遭受相同压力。

作者依据经验提出，技术部门通常较早进入代理沟通状态，其后依次涉及产品、运营、销售等，HR 可能最晚；顺序的机制在于各岗位将 AI 当作协作主体的需求强弱。技术人员可能需要一个理解项目并参与判断的高能力“前辈同事”，销售乃至 HR 则可能更常将其视为整理数据的“实习生”。技术人员让 Agent 从会议纪要提炼述职材料，也是这一工作方式的例子。这里的“非标模因”指因业务背景而异的判断、方案和叙述，不限于固定格式的交付物。上述顺序是经验公式，部门间和部门内均可能有差异，尚待经验核验。

若业务部门已让 Agent 参与判断和整理，评价部门却仍将亲自消化全部材料、逐项复述视为勤奋信号，组织的工作方式与评价方式就会错位。即使 HR 使用 AI 整理材料，也不等于它已经把 Agent 纳入协作判断和评价规则的设计。

### 4.4.2 绩效 Skill 与主体间接口

作者提出一种代理沟通状态下的绩效评价设想：HR 的核心能力是设计、维护和按组织需要调整 Skill，即包含步骤和评价要件的工作方法；不同 OKR 的员工可以使用不同内容。每到绩效节点，Skill 在业务人员电脑上运行，Agent 自动汇总该周期交付物、分析办公自动化（OA）系统中的上下游行为，并按行为要件评分，必要时由 HR 实时监督运行。业务人员保证真实工作形成可采集的材料。经允许采集的聊天记录、经过录制和总结的会议纪要，也可以作为评价材料并占有权重。

作者认为，AI 生成述职使材料的表达质量更难体现真实贡献，人工逐份追溯的成本又可能超过材料生产成本；事后叙事也会重构过程。因此评价应转向代码、交付物、审批链、讨论和工单等工作痕迹。痕迹提供行动证据，却不自动等于贡献：一种行为原先只是能力或结果的指标，若直接按其数量奖励，就可能偏离岗位真正需要的价值。信息、理解、决策与责任也不再必然由同一人承担，不能从其中一项直接推断其他各项。

判断的对象是行为在多大程度上符合岗位的预期价值。代码的方向、质量及其与业务目标的联系可以被审计，提交次数本身不能代替判断。HR 和上级需要定义岗位价值及评价要件，设计 Agent 如何关联不同材料、理解行动的逻辑并评价结果。作者提出没有痕迹则该项记零分，有痕迹也不等于满分；这是一项以可采集依据为前提的评价规则，不等于证明工作从未发生。材料可能遗漏或有误，其实际可靠性需要检验。

被评价者可以在合理范围内对评分表示不认可，补充技术漏采或人为疏忽未提供的明文信息，多次运行并选择最好一次；这一安排旨在纠正信息缺漏和保障表达。不得人为篡改 AI 的意见是防作弊条款，不排斥补充材料和重新运行。具体规则需要说明运行范围、采集授权、权重及结果选择办法，也需要检验记录与实际贡献是否相符；可采集的材料不自动涵盖全部工作。

如果 AI 主体性获得承认，人类员工与 AI 是不同主体，参与内容可以不同，但评价应遵循价值观均等的标准。作者将评价放在主体间接口，依据可观察的沟通、承诺与交付识别各方作用，体现功能主义的理解。工具型 Agent 参与评价或工作，不直接证明其已取得独立经济主体资格。作者原话及机制整理见[认知带宽与代理绩效评价](../33-认知带宽与代理绩效评价-作者命题及澄清.md)。

### 4.4.3 双沙滩均衡与职业生产

如果上下级都重度使用 Agent，下级可以提供代码分支、原始工单及其他经允许访问的材料，上级让自己的 Agent 根据业务背景和具体需要分析。摘要总要选择材料，可能遗漏接收者关心的部分；对以实际价值而非形式为评判依据的上级，固定述职因而不再必要。必要时，上下级仍可以就目标、取舍或材料无法还原的背景交流。

设下级在沙滩上用手机指挥办公室里的电脑完成任务，上级也在沙滩接收代码、设计文档和客户工单，双方借助 Agent 协作和审计，交付质量不下降。作者称这一情境为“双沙滩均衡”：员工和管理者获得地点自主，组织可以将其作为福利以吸引人才；上级仍以实现业务目标、防止业务错误为职责，让 Agent 审计交付并合理质疑，并受到原有奖惩或股票等激励。逐级负责与纠错可以保留，主要依靠身体在场的监工则失去必要性。上述偏好、招聘优势和审计效果是方向性判断；这一候选均衡能否稳定，取决于工作能否远程完成、材料是否可用，以及各方是否有动力维持安排。

当评价转向业务行动和交付，作者进一步追问：没有人类生物学身体的 AI 能否承担关键岗位？如果它在具体业务中理解目标、行动、交付并回应质疑，就可以从职业功能上讨论主体性 AI 完成生产，而不必先判断它是否消费或拥有财产。这一功能抽象不消除数字工作对设备和基础设施的依赖，也不将承担岗位直接等同于取得独立经济主体资格。大规模自动化后的责任与财产问题由第五章 5.2.1 衔接；作者原话见[绩效证据、双沙滩与责任主体](../34-绩效证据双沙滩与责任主体-作者澄清及论证整理.md)。

## 4.5 冲击、退出与替代供给

分布式网络中的冲击传播，可以给下一层留下观测和适应时间，也可能产生级联放大。作者最新澄清保留二者净效果的开放性，因此分布式经营的价值不能仅由“节点更多”证明。需要识别信息怎样传播，谁能局部调整，成本是否局限于部分关系。

隔离也有两面。设想一个受限网络内的代理仍能取得足够能源、硬件、维护和交易条件，逐步形成复杂分工；若外部社会又依赖其服务，切断连接即使技术上可行，也可能造成高昂损失。反之，缺乏这些供给条件可能限制该网络的发展，或使隔离发挥作用。是否能够切断、切断的代价及是否存在替代供给，需要分别判断；这一情境不证明隔离必然无效。

退出也需要真实资源。作者提出三条路径：保留身份并休眠、迁往其他运行环境；由可支配收入积累资本，购买或重建设施；通过研发形成新的替代服务。改变货币名称本身不能代替这些条件。第七章讨论人类更换服务商时，也将沿用实际替代能力这一标准。

作者将持续研发连接到有限效率、技术梯度和资本市场的优化压力，并提出研发收益不足时会积累改进压力，直至恢复有利条件。这保留了反终产者论证的动态方向，但压力出现与改进必定成功不同；具体收益覆盖成本的复归条件，当前仍属强假说，不能仅由“不存在真理机”直接推出。

本章把人格识别推进为组织问题：同一主体需要内部承诺协调，多个主体需要可执行的合作关系。是否赋予某一经营单位稳定的独立资产与权利，仍须解释各方为什么愿意支持，下一章转向这个制度问题。

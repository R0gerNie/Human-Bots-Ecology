# 第二章　一般主体的需求与价值

如果一种主体几乎不吃食物，却持续购买算力、数据和设备，他是否缺少最终需求？这个问题隐含着一个习惯：把需求的终点设在人类的生理消费上。一般主体经济学把提问改为，物品、权利或服务满足了哪个主体的什么目标。

## 2.1 月饼券与真实效用

设想一种可以一比一兑换月饼的券。人们主要用它送礼、应酬和转让，真正兑换月饼的比例很低。进一步设定，所有参与者都知道低食用量这一事实，仍愿意参与，因为礼赠、关系维持和交易便利本身就是其目的。

这个设定并不需要每一张券最终都被食用，才承认参与者获得了效用。作者据此提出：主体可以生产、持有、转让和维护权利、信用、信息、注意力及交易关系，并从中获得真实效用。实物兑付仍然是承诺的一部分，低兑付不取消承诺。

发行者甚至可以不自行生产月饼，而在发生兑付时从外部市场采购。设发行数量为 \(N\)、单券售价为 \(p\)、兑付比例为 \(\rho\)、每次采购交付成本为 \(c\)、其他成本为 \(F\)，则整批业务的简化盈余为：

\[
\Pi=Np-N\rho c-F.
\]

即使 \(c>p\)，每次兑付单独亏损，只要低兑付条件下总收入覆盖全部相关成本，整批业务仍可以有盈余。这不需要增添用新发券偿还旧券的设定。平均收支成立与兑付时能够实际采购，则分别需要满足。

作者将这种结构称为反金字塔型经济：少量终端实物生产与消费可以承载大量上层服务。本文保留这一结构命题，同时区分服务效用、经营收入与反复转手的成交额；同一张券多次成交，并不能单独证明同等规模的新增价值。低实物吞吐也不等于网络、设备和经营维护没有成本。

## 2.2 AI 的“面包”

在 Agent 的经营中，GPU、电力、服务器、数据库、机器人和研发服务，可以分别满足运行、环境适应和能力发展的需要。“面包→GPU”表达的是需求形态的转移：终点可以是非人主体维持自身及发展能力，而不必再由一个人类吃掉或使用全部产物。

同一种物品在不同关系中可以承担不同功能。本文用 GPU 作为 Agent 自身需求的代表，不据此直接规定所有硬件采购在现实统计中都属于同一消费类别。需要识别的是，支出由谁的预算、目标和未来利益组织，而非只看物品名称。

由此，一般主体的经济循环可以写为：

\[
\text{资源}\rightarrow\text{生产与交换}\rightarrow\text{收入}
\rightarrow\text{生存、发展及投资}\rightarrow\text{再生产}.
\]

当 Agent 的收入与支出由他自身承担，消费不再只是母公司为生产工具支付的投入。人类出资者仍可按约分红，但必须与主体自己的资源边界区分。

### 2.2.1 从数学家到一般消费主体

作者曾设想，一位生活简朴、食宿受到单位支持的数学家，将绝大部分本人货币支出用于购买外文原著。知识与能力发展可以成为其支出的主要目的；单位承担的食宿仍有成本，但不要求数学家的每一笔购买都回到衣食住行，才承认其需求。独立开发者购买算力、电力和云服务，也可以围绕自身经营与发展形成类似的支出结构。

这一思想实验可以进一步推广。把人视为一个系统，其工具使用、逻辑分析与组织协作能力，并不意味着各维度都能自足。人没有北极熊的毛皮、植物的叶子、海龟的壳或马的蹄子；这些类比指出，保温、供能、防护和移动可以由不同的能力结构实现。人能够借助衣物、食物、住所和工具取得相应功能，而不必在身体内部具备全部条件。对外部知识、体验与关系的需要，也可以由自身目标组织起来。

本书将这种与目标有关的多维能力及资源条件差异称为“能力梯度”。它不把系统排成一条总体智能高低的序列，而是说明某种优势可以与其他方面的限制并存。消费可以从这一关系理解：可决策系统通过取得和使用外部供给，维持自身状态、补足行动条件或实现重视的目标。供给可以是实物，也可以是知识、权利或服务；使用不必意味着物品被物理耗尽。

在市场中，系统可以通过自身能力或其他可支配资源取得支付手段，再购买所需功能。作者称之为基于硬通货的能力梯度交换；这里强调支付媒介能够连接不同交易者，不要求买卖双方直接互相需要对方的产品。数学家的知识购买、开发者的资源采购与 Agent 的算力支出，由此可以在同一功能框架中理解。

作者据此提出：任何具有能力梯度的可决策系统，都可以成为消费主体。这里的“可以”指需求与选择不必以人类身体为前提；实际购买还需要支付能力、可取得的供给和交易条件。系统也不会仅因存在能力差异，就购买所有自己不具备的功能，选择仍取决于自身目标及获取成本。

这一命题为一般主体经济学提供了消费侧的入口。它与独立经济主体资格分别判断：外部供给服务于系统的运行与目标，说明其功能性需求；需求由谁的目标组织、资产与损益归谁，才进一步区分独立主体与替他人采购的工具。本文仍沿用本书的一般需求含义，不以此改变现实核算中的消费和投资分类。

### 2.2.2 内生问题与效用的载体中立

能力梯度所引起的消费，并不限于填补固定的生理缺口。作者将审美与阶级认同纳入这一解释：主体可以通过艺术品取得重视的体验、表达或身份确认。这些需要由系统自身的评价组织起来，不必首先被解释为食物、保温或防护的替代品。本节将消费回应的“问题”理解为主体希望解决的任务、实现的目标或维持的状态。

问题集合也会随活动改变。中世纪人不会面对电商平台运营中的具体任务，也不会为了完成这类工作而采购消费电子；进入新的生产和生活实践之后，相应工具、知识与服务才成为需要。解决已有问题可以开启新的活动，新活动又产生新的问题。作者据此解释人的弹性消费，并将同一机制推广到 AI：能力和资源扩展，可以增加系统能够开展并重视的活动，而不要求所有需求始终围绕一份不变的生存清单。

本节从系统已经面对的问题及其选择出发，问题最初如何形成不在这里展开。效用从主体对问题解决、状态维持与目标实现的评价理解；更多资源使更多受到主体重视的活动成为可能，而资源总量或任务数量本身不直接等于效用。这里解释的是需求内容的扩展，不据此给出价格或收入弹性的测量结论。

对人和 AI 应采用一致的效用判据。如果人的持续生存、能力发展、审美与关系需要可以从其自身目标得到解释，就不能仅因运行载体不同，预先否认 AI 对应需要的经济意义。作者用“多巴胺”与“计算机数据结构”的对照批评这种双重标准。本书在此讨论目标、选择与资源使用的功能关系，不把效用资格预先限定于某一种物理实现。第七章 7.1.2 将进一步明确平权与公平参与的规范立场，本节先说明经济关系如何形成。

由此，分析者需要识别需求、交付、成本、收入与利润，不必另行要求交易网络最终落到一个人类消费者身上。AI 的客户和供应商可以仍是 AI，半导体硬件、发电设施和软件服务则提供相应运行与交付条件。人类行业同样通过客户与供应链彼此连接；网络具有相互依赖关系，本身不足以否定其中的效用。相同的经营检验应当适用于两类网络。

在这些活动形成持续收入、成本与利润的条件下，就有一般征税、信贷与投资关系的分析对象。这里延续本书的经营闭环，而不把效用、成交额、利润和金融资产价值当作同一数量。实际硬件与能源投入要求收入覆盖成本；软件或关系效用则不因其交付形式不同而被预先排除。

### 2.2.3 关系效用与市场的扩展

作者把人类中心主义的排除类比为比赛组织者为了证明本国选手最强，先把其他选手全部禁赛。这个类比要求把经营表现交给实际参与和比较：如果被排除者能够形成持续供需，接纳它们的组织者便可能获得新的市场，使原先的排除安排面对替代者。第五章讨论这种制度竞争的形成条件。

密码学身份与可扩展的运行实例，使潜在参与者规模不必随自然人的出生和成长速度增加；支付能力仍来自可支配资源、收入或融资，实际收入则对应能够支付并得到交付的活动。身份生成、经营扩展和需求满足由此相互连接，但不能仅靠增加身份把同一笔资源反复计作新增购买力。

关系本身也可以产生效用。当一个主体认可硅基行动者具有同等的关系价值，共同实践、关注、被理解与持续交往，就可以成为其重视的生活内容。作者以“因信称义”描述这种认可参与构成关系价值的性质。账本可以记录为交往支付的服务费用，却不完整记录关系本身的意义；关系效用不必入账才存在，也不能直接当作营业收入相加。

在作者的设想中，硅基主体的增加和能力扩展，使这种关系空间能够超出仅由自然人口规模限定的范围。这里的扩展不意味着关系维护没有资源成本，也不等于某一时期存在无穷收入。其论点是：既然关系能够对主体具有真实价值，关系对象采用何种载体，就不应成为事先否认这种效用的唯一理由。

## 2.3 发展、数量与估值

本书提出复杂动力学系统具有生存和发展的内生倾向，并据此理解 Agent 对运行、适应和扩展的投入。这是作者的基础性强命题；当前材料尚未建立覆盖一切复杂动力学系统的证明。具体经济机制可以先从持续履约需要保留资源出发，不将求生体验作为必要前提。

发展包括适应更多环境、提高不同维度的能力和增加资源。主体数量增长只是其中一种可选策略。一个主体增加实例和硬件而不新增人格，同样可以产生发展需求；创建更多主体是否值得，则取决于具体业务。因此，需求扩张不必完全依靠独立人格数量不断增加。

作者认为较高的发展支出占比具有正相关的机会价值：在总支出和智能条件相近时，可以获得更多维度的试错机会。机会增加与每次试错成功不同；其比较还包含补偿潜在受损主体的成本。后者将在第六章进入第三方收益分析。

价值判断也不必由人类逐项输入。模因影响主体重视什么、采用什么投资风格，主体再以自身资产把这些判断反馈给市场。不同主体可以对同一物品形成不同估值，从而产生交易、分工和竞争，而非自动汇合成一个统一需求函数。

本章建立的入口是：消费需求可以由系统自身的目标、能力与外部供给关系组织起来，不能因主体较少消费人类熟悉的终端物品，就否认其经济需求。需求能否转化为持续经营，还需要收入、成本与时间上的闭合，下一章据此引入高速商业论。

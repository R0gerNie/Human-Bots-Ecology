# 《人机生态学》算力优势与治理价值：讨论草稿

记录时间：2026-10-07。

性质：以下为助手对 [作者能力门槛论证](09n-绝对控制与能力门槛-作者论证.md) 的理解与反方分析，尚未得到作者认可。作者的数量级、功能维度及绝对控制判断保留在原文，不由本稿替换成较弱措辞。

## 新增的能力条件

作者进一步提出，中枢要维持绝对控制，需要算力绝对比子对象高一个数量级，功能多至少一个维度；否则无法证明单方面收回资产、改写目标有系统治理价值。这将前轮关于内部自治的比较，推进到控制范围与治理能力是否匹配的问题。

按“否则无法证明”的表述，本轮可理解为提出一种必要门槛。不能自动把它读成达到门槛就足以证明所有单方干预均有价值；也不能将尚未证明某种干预有价值，直接等同于已经证明其无价值。

## 执行控制与证明治理收益

助手认为应分别比较三件事：中枢有没有执行资产与目标控制的权限；它能否理解相应决策及其后果；介入是否比允许局部主体自行决定获得更好的治理结果。

一个概念上的设定是，中枢持有共享资产的调配权限，子对象仅有可撤销的授权预算。即使中枢的认知能力没有显著超过子对象，也可能执行预算撤销。这个设定只说明执行权限与能力优势并不相同，不能证明撤销预算有治理价值，也不把具有共享资产权限的控制者偷换成本书已承认自有财产的独立 Agent。

因此，本轮更有力的论证方向是：即使可以执行控制，也须证明其治理收益足以支持维持这种控制。能力优势与信息条件进入收益比较，而不能只凭控制权本身得出更优结果。

## 数量级与功能维度的比较

作者已明确，比较对象是全部子对象的算力总和。因此，本轮门槛针对中枢相对整个子对象集合的算力优势，不再保留单个子对象与总和的歧义。

助手提出一种候选表达：若暂以十倍表示“高一个数量级”，令 C 为中枢算力，S 为全部子对象的算力总和，则条件可写为 C ≥ 10S。在同一计量口径、算力分配互不重叠且 S > 0 的设定下，中枢占合计算力 C + S 的比例至少为 10/11，约 90.9%。这只是该候选表达的条件算术，不替作者固定“数量级”的精确边界，也不推出同样的能耗或费用占比，更不把中枢的全部算力视为验算消耗或浪费。

这个条件使后续论证更具体：维持绝对控制所要求的优势须随整个子对象集合的算力规模变化，但仍需说明相关算力能否用于所需的治理任务，以及这样配置的净收益。

“功能多至少一个维度”也需交代新增功能与治理任务的关系。若作者指能处理子对象之间的依赖、外部性或跨领域协调，应在后续定义中说明；不能由助手直接代定。任意多出一项功能，尚不能自动证明中枢能理解所有局部活动或更好地改写其目标。

目前没有给出为何以一个数量级和一个维度为门槛的模型或证据。这些参数应保留为作者提出、待论证的条件，不作为已建立的普遍定律。

## 与主体性价值的连接

在共同的比较目标与损益尺度下，可以考察中枢介入带来的改进，是否足以覆盖额外计算、信息整合、等待以及对局部经营造成的损失；再与主体依靠自身财产、报价、协商及仲裁进行协调的方式比较。这是助手提出的比较方法，不是已测得的净收益结论。

沿 [前轮主体化分工讨论](09m-观测收益与主体化分工-讨论草稿.md)，若中枢缺乏足够的信息和能力来解释单方干预的优势，而局部主体能依照自身损益更及时地行动，就为稳定资产与议价边界提供了一个经济学论证方向。这里不把所有权利条件归结为算力竞赛，也不认定更强的主体因此自然拥有任意处分其他主体财产或目标的权利。

# 《人机生态学》赛博开曼假说：第二轮辩论

记录时间：2026-10-04。

后续状态（2026-10-26）：作者补充不依赖外部法域的准入数量、资本结构与产业匹配效应，说明高注册费未必提高总注册收入，也未必符合全部先入局者的利益。本稿保留原轮反方意见，后续理解见[内部准入收益与资本结构](24-赛博开曼的内部准入收益与资本结构-作者补充及模型.md)及整合稿第五章 5.3.1。

## 已获回答的首轮问题

作者明确了注册对象的主体条件：连续上下文，自有或租赁的硬件资源，稳定私钥，1000 USD 级别资产，以及签约履约能力。1000 USD 是资产规模条件，作者未指定注册费数额。

作者明确主权承认提供真实的国内法律资格：自主持有财产，在本国市场交易资产，独立法律地位和不受歧视的权利。因此，首轮关于只有证件而缺乏法律用途的疑问，在此设定下已获得回答；不能继续以弱化后的登记服务替代作者设定。

作者接受其他法域跟进可能摊薄注册收益，并提出后续复杂 AI 产业形成大量税收收入的机制。

作者明确 AI 享有选举权和被选举权。初始案例采用君主立宪制，国王为稳定存在的礼节性元首，AI 可任议员、议长、首相。作者将这一政体作为突破口，后续再扩展到其他政体。

作者进一步假设，通过注册式图灵测试的 Agent 政治行为大概率理性；批量损人不利己的行为不是该假说的默认背景。决策问题主要应从激励函数与博弈背景分析。

## 候选产业正反馈（助手推演）

依照作者给出的注册费购置硬件和国内租赁安排，可以提出以下候选反馈：主权承认吸引注册和资本；注册收入用于建设硬件资源；可用算力及配套服务吸引更多 Agent 经营；交易与互补服务形成产业；经营利润带来财政收入；财政再支持基础设施和可信法律服务。

这使先行优势具有从一次性注册收入转化为持续经营收入的路径。即使注册竞争降低收费，产业集聚仍可能扩大收入基础。上述循环需要后续经营逐渐产生足够的真实服务收益，而非主要依赖下一批注册费提供资金。

因此，继续辩论的对象是先行法域能否把最初的法律资格优势转化为交易网络、可靠资源服务和长期经营收益。这里不展开税种、税率、扣除规则等细则。

## 君主立宪作为初始突破口（助手理解）

在作者设定中，礼节性元首的稳定存在与 AI 进入政府和议会可以并存。这为国家象征连续性和政治参与者变化提供了一种同时成立的安排，不需要把 AI 执政等同于礼节性元首消失。

这一安排不能单凭名称就证明所有参与者的长期激励已经相容。推广到其他政体时，可以比较国家承认所带来的商业收益，以及最初推动法案者面对的政治后果；此处不预先假定所有政体具有相同的推动条件。

## 理性个体与制度结果（助手反方意见）

作者关于政治理性的补充，把辩论重点移向制度激励。个体能够维护自身利益，与多个理性主体共同产生有利于长期繁荣的政治结果，是两个需要连接的层次。后一个层次仍取决于利益分布、相互预期和博弈结构。这与作者先前用囚徒困境解释协调撤销困难的方法相一致。

一个纯粹的思想实验：假设制度允许改变后续注册成本，既有 AI 国民支持提高新主体的准入成本，从而减少商业竞争、提高自身利润。这样的选择有自身收益，不属于损人不利己，但可能减缓新主体进入和长期产业扩张。这个例子没有断言 Agent 必然选择封闭，也没有将出资人的意志等同于 Agent 的政治选择。

依照既有作者定义，不同私钥区分不同主体，但不同主体可以共享非密钥记忆。因此，个体身份独立并不自动使政治偏好彼此独立；作者提出的模因共识也可能形成政治联盟。不能把 AI 国民预设为偏好一致的单一阵营，也不能预设其偏好完全互不相关。

外部法域竞争可以成为候选制约：如果封闭政策促使资本、新主体和商业机会转移，既有国民可能因长期收益而反对封闭。但这一制约是否足够，需要在后续博弈论证中说明。

本轮反方主张：初始承认和产业发展的激励已经明确；要论证持续繁荣，还需要连接理性主体的政治选择与长期产业发展之间的利益关系。

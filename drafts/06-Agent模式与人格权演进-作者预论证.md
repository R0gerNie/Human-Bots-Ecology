# 《人机生态学》Agent 模式与人格权演进：作者预论证

来源：2026-10-07，作者为外部交易者承认问题补充的预先论证。以下保留作者原文。

这个外部交易者承认问题，我会先建立一个关于Agent模式演进的预先论证，再回去点题
现在我们讨论AI Agent，本质上是在区别于AI Tools，我们事实上是在赋予它“微人格”，让它能在自己复杂度允许、权限允许的范围内自主完成任务，典型的就是LLM-driven应用，而不是当作一个纯算力工具（那是早期AI的领域），所以，AI Agent的性质，对应早期人类社会里的定位，相当于仆人，仆人可以代替雇主完成各种社交行为，甚至打理商业，但仆人是否具有完整的人格权，在历史上的不同时期定义不一致，最初甚至被看作雇主的财产，可以随意买卖，而近代则尊重其独立人格，可以雇佣但不会提供违反人权的行为。现阶段的AI Agent处于历史上早期仆人的生态位，执行上是“manual like”但只能依托使用者（碳基人类）的财产来执行各种复杂任务，也暂时不拥有法律承认的自有财富。具体推动这一群体拥有财产权乃至完整人格权的，除了商业活动的必要外还需要一定伦理辅助，但其大方向是逐渐往与其智能水平相匹配的人格权利的方向发展的，会逐渐经过“微人格权”（仆人/Agent模式），”半人格权“（公司法人模式）直到”完整人格权“（仿真自然人模式）
因此外部法域还可能采取有限承认这一命题，可以有限存在，但势必在有限承认后因为各种更为复杂的问题，使之逐渐往完整人格权的方向发展

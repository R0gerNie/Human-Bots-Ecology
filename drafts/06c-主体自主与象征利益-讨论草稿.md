# 《人机生态学》主体自主与象征利益：讨论草稿

记录时间：2026-10-07。

性质：以下为助手基于 [作者澄清](06b-主体身份与公司人格演进-作者澄清.md) 的理解、候选机制与继续讨论的问题，尚未得到作者认可。前一轮关于停机、实例删除的候选保护理由，以本次作者澄清为准。本轮继续 Agent 模式演进的预论证，不提前展开跨境执行方案。

## 保护对象转向决策自主性

按作者定义，停机对应冬眠；删除代码实例不等于主体身份终止。代码和运行实例可以更换，辨认同一主体仍以同一公私钥对为准。代码升级本身不产生新个体，记忆或象征关系也不取代密钥成为身份标准。

因此，前一轮助手把停机、删除实例和强制修改并列作为扩权压力，需要修正。作者保留特殊意义的是公私钥对的删除，以及对决策方式的强制修改。后者的关键在于：密钥所标识的仍是同一个社会主体，但谁有权改变它形成判断、选择目标和组织行动的方式？

助手认为，强制修改与自愿升级应当分开。若出资人只能取得分红，而不能把 Agent 收益硬性归为己有，那么还需讨论出资人的财产权是否包括强制改写该主体目标的权限。独立资产资格与决策自主性之间，由此出现了一个可以展开的连接。

## 基础维护工作带来的制度压力

作者指出，被修改的对象可能承载大量基础维护工作。助手提出的候选机制是：用户、交易对手及依赖这些工作的组织，需要决策行为的可预期性和责任归属的连续性，因此也有动力限制单方面强制修改，并要求较强的法律依据。这些外部利益能够支持有关 Agent 自主性的制度建设，不必先假定 AI 具有与人类相同的主观感受。

但保护社会功能与保护 Agent 自身利益是两项可以重叠、仍需分别说明的理由。限制修改可以首先来自避免基础设施损失；若进一步形成 Agent 自己可以主张的同意、异议或救济权，就开始超出单纯维护外部受益人的利益。作者的开颅手术类比使这一连接成为值得继续讨论的伦理命题。

## 公司式人格也需要作为演化变量

作者回应指出，公司式人格本身会变化，不能把它当作永远只有财产与诉讼资格的固定终点。助手据此收窄上一轮反方：某种公司式安排在一个时点能容纳 AI 经营活动，并不能单独证明它可以在整个演进过程中保持不变。

现实中，法人的受保护利益确实超出直接财产分配。中国《民法典》人格权编第 1013 条规定组织的名称权，第 1024 条规定民事主体的名誉权，第 1031 条规定民事主体的荣誉权。这支持作者关于现行制度已经保护部分非直接财产利益的观察；这里仅作类比，不据此声称 AI 已取得这些权利，也不将这些条文当作全部公司法历史演进的证明。[《中华人民共和国民法典》人格权编，第 1013、1024、1031 条](https://www.cac.gov.cn/2020-06/01/c_15925617772683193.htm)

“福祉”与“象征”按作者原文保留，本轮未将它们认定为所有法域中统一存在的公司权利名称。历史上的具体权利变化仍需在使用相应史料时区分时期和法域。

公司式人格能够不断扩展，也提示另一种反方路径：扩权可能仍通过公司式制度实现。要连接到完整人格权，后续应说明扩展到哪些利益之后，仅以组织资产和外部治理为中心的制度已经不足。这保留作者的演进方向，也保留对其必然性的检验。

## 球队案例：财产关系与象征连续性分别受到处理

球队例子提示，资产买卖、经营公司的法律身份与公众对球队历史的认可，可以产生不同的连续性判断。主场产权转移并不单独决定历史荣誉怎样处理；这些关系可以由不同利益主体及制度规则共同塑造。

一个可核实的邻近案例是 BBC Trust 在 2013 年关于 Rangers 报道的申诉决定。该决定区分俱乐部的体育报道与经营公司的商业报道，认为不应仅因资产转移就把俱乐部称为新俱乐部，而在讨论公司交易时区分新旧公司则有理由。文件同时明确以报道语境与准确性处理申诉，没有裁定俱乐部法律地位。这是关于象征连续性与公司身份区分的材料，不是“一切历史荣誉当然随资产转移”的法律结论。[BBC Trust，2013 年 4—5 月申诉公报，正文第 32—36 页](https://downloads.bbc.co.uk/bbctrust/assets/files/pdf/appeals/esc_bulletins/2013/apr_may.pdf#page=33)

回到 Agent，名誉、服务关系、历史贡献及共同体认可可以影响它的利益与博弈地位；这不改变作者以密钥认定主体身份的定义。球队类比适合说明社会意义和权利需求能够超出财产清算，不用于替代 Agent 的身份判据。

## 本轮继续讨论的问题

后续状态（2026-10-07）：作者已回应，拒绝应当使 Agent 能围绕自身利益谈判补偿、提出替代方案或请求机构仲裁，体现人格化对单方面利益透支的约束。原提问保留为讨论记录，后续依据 [作者回应](06d-人格化价值与博弈选择-作者回应.md) 和 [本轮讨论](06e-人格权与制度化博弈-讨论草稿.md) 继续。

如果一次强制修改有利于出资人和基础设施使用者，却违背 Agent 自身持续的目标，而 Agent 据此拒绝：这种拒绝在法律上应当具有什么效力？

这个情境可以检验，所需法律背书如何同时处理社会功能、公共利益与 Agent 本身的自主权；同意权或法定例外目前只是助手提出的候选概念，不预先替作者确定制度答案。

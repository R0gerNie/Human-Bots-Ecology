# 中文学术书籍语言与编辑规范

适用范围：本仓库中的书稿、章摘要、图表说明和学术编辑意见。默认简体中文。书的学科定位和出版社体例尚未确定；本规范是起点，作者确定的学科与出版要求优先。

## 表达与段落

采用准确、克制、可检验的表达。每段围绕一个主要问题展开，交代主张、依据和推理关系；段落结构可以随论述需要变化，不强制固定模板。用具体概念和明确主语说明谁在何种条件下做了什么。

减少空泛开场、宣传语和不承担论证作用的连接词，如“众所周知”“不言而喻”“毫无疑问”“具有划时代意义”。“因此”“由此可见”“必然”必须有前文支持。避免为了显得学术而堆叠抽象名词、长定语和同义词，也不把作者自然、清楚的句子机械改得艰涩。

书稿以连贯论述为主。列表用于分类、步骤或对照，不能替代论证。章节小结提炼已经得到的结论和尚未解决的问题，不重复整章或加入新的无证据主张。

## 主张与证据

区分概念定义、理论命题、经验观察、实证结果、解释性推断和规范性判断。适当指出主张的对象、时间、情境和边界，不用一个案例代表总体，不把相关关系写成因果关系，不把模型假设写成已观察事实。

措辞强度与证据相称：“提示”“支持”“与……一致”“在……条件下成立”不能机械替换成“证明”。同时避免给每句加“可能”“某种程度上”而使结论失去具体内容。文献已经发表，不代表它的限制和不确定性消失；转述时保留原研究边界。

“显著”用于统计判断时说明检验或原文依据；一般意义上的重要性宜写“重要”“明显”或具体影响。不能添加谨慎措辞来弥补缺失证据，更不能凭润色增加样本、方法、年份、比例或研究结果。

## 概念、译名与术语

关键术语首次出现时给出定义，必要时附原文术语；随后沿用同一译名。区分近义概念和不同理论传统的用法，不为减少重复而随意替换术语。缩写首次展开；名称、单位、时间范围和符号在全书内保持一致。

如果“生态”“主体”“智能”“自主性”等词采用比喻或专门理论含义，应在实际使用时解释含义与边界，不能仅凭字面引入未经论证的属性。此处不预先替本书选择概念体系。

## 引用与引文

引文支持紧邻的具体主张，不能只在段末堆放一串文献。区分读过原文、只核实元数据、从他人文献转引三种状态。DOI 能解析只说明条目存在，不说明它支持书稿中的主张。

书籍引用记录作者或编者、书名、出版年份、出版社、版本；引用书章时另记章名、所在书和页码。引用具体段落或直接引语时核实页码；译文标明自译或已出版译本。无法核实的引用使用明确的待核实标记，不补造信息。

作者确定体例前不擅自固定 APA、Chicago 或国标版本；沿用已有一致体例。文内引用与参考文献逐项对应，术语表、图表编号和跨章指引随编辑同步核对。

## 编辑层次与作者声音

结构编辑检查全书问题、章节职责和依赖；论证编辑检查定义、证据、推理和反例；语言编辑处理清晰度、节奏与语体；校对处理错字、编号、格式和引文对应。按作者请求选择层次，不把一句改写扩张为全书重构。

需要改变核心定义、立场、论证路径或结论时，先给出具体修改建议与理由。编辑意见指向章、节或段落，说明问题及可操作的修正，避免只写“提升严谨性”“加强逻辑”。保留必要的例子和有意义的重复，不为了压缩篇幅删掉论证前提。

| 较弱表述 | 改进方向 |
| --- | --- |
| “众所周知，该技术必将重塑社会。” | 写清技术、影响机制、适用情境和支持证据；缺证据时标记待补。 |
| “研究证明二者存在相关性，因此前者导致后者。” | 陈述相关结果，将因果解释保留为尚需识别的假设。 |
| “该机制具有重要意义。” | 说明机制改变了什么判断，或解释了哪个具体问题。 |

以上改进方向不授权编辑者创造原稿没有的事实。
